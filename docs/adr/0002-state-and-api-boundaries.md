# ADR-0002：状态与 API 边界

状态：Accepted。日期：2026-10-18。

## 背景
列表、详情和仪表盘需要共享一致数据；列表查询需要可分享、可恢复。重复保存服务端数据、URL 查询和客户端状态会产生状态漂移。

## 决策
- Axios 客户端、Base URL、超时、错误规范化和响应约定集中维护。
- 每个业务模块提供自己的 API 函数；页面不得直接访问 MSW handlers 或拼接主机地址。
- TanStack Query 是服务端数据和请求状态的唯一缓存事实来源。
- URL 是已提交列表查询状态的事实来源；未提交搜索词和筛选项只保存在局部草稿状态。
- Zustand 不存储服务端实体或可由 URL 表达的列表状态。
- 公共 API 层不直接弹出 UI 提示；页面和表单负责呈现错误。
- 4xx 不自动重试；可重试网络/超时/服务端查询错误最多重试一次；写入不自动重试。
- 变更后通过集中 query key 与失效策略刷新受影响数据。

## 后果
刷新、分享链接和浏览器前进/后退能够恢复已提交查询；草稿变化不触发列表查询。API 契约变更必须同步类型、业务 API、MSW handlers 和测试。
