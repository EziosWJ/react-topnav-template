# ADR-0004：DataTable 公共契约

状态：Accepted。日期：2026-10-18。

## 背景
业务列表需要统一分页、排序、列管理、选择、批量操作和导出体验；组件支持业务配置，但不能吞并业务规则。

## 决策
- rowKey 必须由调用方显式提供，为稳定唯一字段或提取函数；禁止默认使用数组索引。
- DataTable 负责通用交互和状态协调；业务页负责列定义、允许排序字段、查询回调、数据获取、导出映射和批量业务动作。
- 搜索/筛选草稿由列表页管理；点击查询或按 Enter 才提交并触发请求。重置恢复默认查询条件并重新查询。
- URL 保存已提交搜索、筛选、排序、分页和页大小状态。
- 当前页选择和跨分页选择由业务配置；组件统一处理 keys、选中行和批量操作上下文。
- 提供列显隐与三档密度；列宽通过列配置设置，不提供拖拽调宽。
- 服务端分页排序必须受控并应用于完整查询结果，不得仅对当前页本地排序。
- 导出全部筛选结果与导出选中行是两个明确不同的操作范围。

## 后果
rowKey、搜索提交、URL 同步、选择策略或批量操作上下文变更属于公共契约变更，必须更新本 ADR、SPEC-0003 和测试。
