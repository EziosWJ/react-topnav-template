# ADR-0005：MSW 模拟 API 与无持久化边界

状态：Accepted。日期：2026-10-18。

## 背景
模板需要在没有真实后端时可启动、演示和测试，同时避免将演示能力误认为生产持久化服务。

## 决策
- 使用 MSW 拦截与真实 API 契约一致的请求。
- 开发环境默认启用 MSW，生产默认关闭。
- 种子数据和写操作结果只保存在当前运行时内存。
- 刷新或重启应用后恢复种子数据；不将模拟业务数据写入 localStorage、IndexedDB 或真实服务。
- 上传只演示校验、进度、成功/失败和重试，不发送文件到服务器，也不写入业务实体。
- handlers 模拟关联完整性、分页、筛选、排序、字段校验和冲突错误。

## 后果
演示数据不具有持久化保证。连接真实 API 时应关闭 MSW 并替换业务 API 实现，同时保留类型、错误契约、查询键和 UI 行为。
