# ADR-0006：CRUD 表单与危险操作

状态：Accepted。日期：2026-10-18。

## 背景
列表快速操作需要高效率，复杂表单和详情需要可直接导航；危险操作必须避免误触并清楚反馈结果。

## 决策
- 列表独立成页；简单新建和快速编辑可以使用 Drawer。
- 详情与复杂/完整编辑使用独立路由；本仓库已有的独立新建路由应保留。
- 表单打开前清理旧错误与 mutation 状态；编辑表单从实体映射初始值。
- 提交期间展示 loading 并阻止重复提交。
- 保存成功后明确反馈并关闭 Drawer 或导航；失败时保留输入并展示通用错误或字段错误。
- 删除及启用/停用等有副作用操作必须确认；删除引用中的客户/项目由模拟 API 阻止并解释原因。
- API/公共组件层不重复弹出错误提示。

## 后果
新增或调整 CRUD 交互时同步更新业务 SPEC 和页面测试。不能仅为了视觉一致而删除确认、校验或失败反馈。
