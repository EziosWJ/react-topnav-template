# SPEC-0003：列表查询状态与 DataTable

状态：Accepted baseline。日期：2026-10-18。落实截至第 97 轮已确认的列表与表格决策。

## 1. 搜索与筛选必须显式提交
搜索关键词和筛选控件使用草稿状态。编辑输入或选择筛选项时：
- 不得立即改变 URL 中已提交的 keyword/filter。
- 不得仅因草稿变化而发起新的列表查询。
- 当前列表继续展示最近一次已提交条件的结果。

点击“查询”或在搜索框按 Enter 时，将关键词与所有筛选项一次性提交，去除关键词首尾空白，并把页码重置到第一页。URL 只同步提交后的关键词和筛选值。

点击“重置”时，清空关键词和筛选草稿、恢复默认排序/分页等列表默认条件，并立即重新查询。只清除列表拥有的 query 参数，尽可能保留无关 URL 参数。

## 2. URL 与历史导航
- 已提交关键词、筛选、排序、页码和页大小同步到 URL query。
- 刷新、分享链接、浏览器前进/后退必须恢复同一份已提交列表状态。
- 输入过程中不得因每次击键产生大量浏览器历史记录。
- 纠正非法页码等规范化动作时应避免创建会困住 Back 的历史记录。
- 非法页码、页大小、排序字段/方向、筛选枚举和日期应安全回退或忽略。
- 提交新查询、改变筛选或排序时页码回到第一页；调整页大小时页码也回到第一页。

## 3. 排序与分页
- DataTable 排序为受控状态，由业务页提供允许字段与回调。
- 排序字段必须白名单校验。
- 分页、页大小、排序变化后同步 URL 并重新查询。
- 服务端分页场景不得只对当前页做本地排序并冒充全量排序。
- 总数缩小时若当前页超出范围，自动切换到最后一个有效页，并使用 replace 语义。

## 4. 稳定唯一 rowKey（第 97 轮）
每个 DataTable 调用必须显式配置稳定且唯一的 rowKey 字段或提取函数。
- 禁止把数组索引作为默认 rowKey 或业务选择标识。
- rowKey 在排序、分页、筛选、数据刷新和 CRUD 前后保持稳定。
- 若实体没有稳定唯一标识，先修正实体/API 契约，不得用索引掩盖问题。
- 通过 TypeScript 类型约束或开发环境检查，对缺少 rowKey、空 key 或重复 key 给出明确提示。
- 选中行、缓存行、行操作和批量操作均使用同一 rowKey 契约。

## 5. 选择策略（第 96 轮）
DataTable 支持两种由业务配置的选择策略：
- 当前页选择：只保留当前页有效选择，不将离开当前页的行错误地当作当前页选择。
- 跨分页选择：翻页后保留用户明确选择的行，并以稳定 rowKey 关联已选实体。

通用 DataTable 负责选择状态、已选 keys/rows 和批量操作上下文；业务通过 batch action 接口定义实际操作。批量操作明确目标范围、数量、成功/失败反馈和清除选择行为，不能混淆“当前页”与“全部筛选结果”。

## 6. 通用表格能力
- 列定义由业务显式提供，列宽通过列配置定义；不提供拖拽调宽。
- 可配置列显隐；操作列等关键列可设置为不可隐藏。
- 提供大、中、小三档密度。
- 支持受控排序、分页、加载/错误/空状态、重试和批量操作工具栏。
- 通用组件不负责行点击导航，不内置具体业务排序或 CRUD 逻辑。
- 响应式时允许表格区域横向滚动或使用列响应式配置，不应导致整个页面失控横向溢出。

## 7. 导出
- “导出当前结果”是当前已提交搜索/筛选/排序条件下的全部匹配结果，不只是当前页。
- “导出选中”只导出所选范围记录；跨分页模式必须包含跨页已选记录。
- CSV 使用 UTF-8 BOM 和正确转义；XLSX 中文列名、日期和金额格式应可读。
- 导出列、字段格式化、文件名和工作表名由业务配置或统一工具负责。

## 8. 必需测试
覆盖草稿编辑不请求、点击查询、Enter 提交、重置后查询、URL 刷新恢复、Back/Forward、非法参数回退、排序/分页/页大小同步、当前页/跨页选择、稳定 rowKey、列显隐、密度切换、全量筛选导出和选中行导出。

## 9. 实现一致性
本 SPEC 是目标契约，不代表当前代码已自动满足所有条款。按 docs/acceptance.md 记录的差距逐项修复；不得为了迁就现有实现而削弱规范。
