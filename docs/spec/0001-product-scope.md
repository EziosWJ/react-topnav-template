# SPEC-0001：产品范围与页面能力

状态：Accepted baseline。日期：2026-10-18。

## 1. 产品定位
React Topnav Template（顶部导航管理后台） 是可独立运行、可复制定制的 React 企业业务管理后台脚手架，提供业务模块、列表/表单交互、模拟 API、可复用组件和自动化测试基础。

## 2. 目标与原则
- 页面与数据流完整可演示，不以静态截图或无效按钮冒充功能。
- 核心业务模型、模拟 API 契约和主要交互与另一个模板一致，但布局和导航独立实现。
- 实现必须遵循已确认决策、Accepted ADR、SPEC 和验收清单。
- 保持轻量、可理解、可测试，不引入未经决策批准的第二套框架。

## 3. 范围内模块
### 仪表盘
展示客户、项目、订单和业务用户核心指标、项目状态分布、订单趋势/金额趋势与最近订单。支持现有的 30 天、90 天、12 个月时间范围；数据由模拟 API 驱动。

### 客户管理
支持关键词搜索、状态/行业筛选、排序、分页、创建、编辑、详情、删除、导出及模拟导入。详情展示关联项目与订单。仍被业务记录引用的客户不能删除。

### 项目管理
支持项目列表、客户/状态/负责人/日期等现有筛选，创建、编辑、详情、进度/预算/日期展示及关联信息。仍被订单引用的项目不能删除。

### 订单管理
支持订单列表、关键词与客户/状态/日期筛选、创建、编辑、详情、删除和导出。订单关联客户，可按现有模型关联项目；金额和日期使用统一格式化工具。

### 用户管理
维护演示用业务用户资料，包括姓名、用户名、邮箱、部门、岗位/角色、状态和最近登录等现有字段。此处的“用户”不代表系统登录账号或权限主体。

## 4. 通用能力
- 统一路由与导航元数据、面包屑、页面标题和中文文案。
- 统一 API 客户端、错误规范化、查询缓存和失效策略。
- DataTable：受控排序、分页、列显隐、三档密度、选择策略和批量操作入口。
- 搜索/筛选显式提交；URL 保存已提交查询、排序和分页状态。
- CSV/XLSX 导出全部匹配结果或明确范围的选中行。
- 模拟上传：类型/大小/数量校验、进度、成功/失败与重试/预览；不上传文件，不写入业务数据。
- 加载、错误、重试、空数据、字段错误和危险操作确认。
- 浅色/深色主题、响应式布局、键盘操作和可见焦点。

## 5. 明确不在范围内
真实后端和业务数据持久化、登录/认证/密码/授权/权限/审计服务、真实文件上传或导入入库、Docker/Nginx 部署、Tailwind、第二套图标库、Storybook，以及与另一个模板共享代码包、workspace、submodule 或运行时依赖。

## 6. 本模板专属边界
- 导航形式：顶部导航、下拉子菜单和宽内容区。
- 全局命令面板可通过按钮或 Ctrl+K / macOS ⌘K 打开。
- 小于 992px 时切换为 Drawer 导航。
- 不提供应用内页面标签栏。
- 品牌视觉采用蓝紫色。
- 业务模块的列表、新建、详情和编辑按当前仓库路由与 Drawer 组合实现。
